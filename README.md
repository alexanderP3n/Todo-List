Простое приложение для управления задачами, созданное с использованием React/Typescript и Material-UI (MUI).

## 🛠 Технологии

- **React 19** - Библиотека для построения пользовательских интерфейсов
- **Material-UI v7** - Компоненты Material Design для React
- **TypeScript** - Статическая типизация
- **Vite** - Сборка и development-сервер
- **Emotion** - Стилизация компонентов
- **ESLint** - Линтинг кода

## 🔧 Конфигурация

tsconfig.json: Настройки TypeScript
.eslintrc.\*: Правила линтинга для TypeScript и React
vite.config.ts: Конфигурация Vite с плагином React
